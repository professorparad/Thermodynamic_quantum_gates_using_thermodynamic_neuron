Interpretation:
The Floquet term is local on the buffer, so it does not change spatial graph treewidth. It can nevertheless increase the numerical Schmidt ranks by generating more entanglement. A topology-matched TTN isolates each reservoir branch with a single graph edge, whereas an MPS must choose a linear ordering and can carry several branch correlations through one bond. The calculation is an exact small-network evolution followed by exact Schmidt analysis and Quimb MPS factorization; it is not yet a large-chain TDVP/TTN time evolution.
